Vấn đề của code cũ (Statement trong loop)

```java
for (...) {
    String sql = "INSERT INTO lab_results VALUES (...)";
    Statement st = conn.createStatement();
    st.executeUpdate(sql);
}
```

Điều gì xảy ra bên trong DB (RẤT QUAN TRỌNG)
Mỗi lần chạy SQL, Database phải:

1. Parse (phân tích cú pháp)
   •	Kiểm tra SQL đúng không
   •	Phân tích cấu trúc

2. Optimize (tối ưu)
   •	Tạo execution plan

3. Execute (thực thi)
**Với 1000 bản ghi**
   **DB phải làm: Parse + Plan + Execute  x 1000 lần**
   ➡️ ❌ Cực kỳ lãng phí CPU
   ➡️ ❌ Tốn thời gian lớn

👉 Cấu trúc SQL KHÔNG đổi, chỉ đổi dữ liệu

Giải pháp: PreparedStatement
chỉ
**Parse + Plan = 1 lần duy nhất
Execute = 1000 lần**

# Lab Result Performance Optimization

## Problem
Using Statement inside loop causes:
- Repeated SQL parsing
- Repeated execution plan creation
- Slow performance

## Solution
Use PreparedStatement:
- Pre-compile once
- Execute multiple times

## Improvement
- Faster execution
- Reduced database load

## Bonus
Use batch execution for maximum performance
